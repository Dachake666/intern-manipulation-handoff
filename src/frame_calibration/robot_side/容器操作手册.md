# 真机采数 · 容器操作手册

> 适用环境：Linux 操作电脑 Docker 容器（`humble_ros_core`，Python 3.10 + pypilot）。
> 本目录（`robot_side/`）整个拷进容器即可运行，采集数据写到 `./data/`。
> 分析全部在 Mac 上做，本手册只覆盖容器内的操作。

## 0. 准备（每次开工前）

```bash
# 1) 把本目录拷进容器工作区(示例路径)
#    /home/dev/workspace/sdk_tests/frame_calibration/
cd /home/dev/workspace/sdk_tests/frame_calibration

# 2) 确认脚本顶部 IP 与当前实际一致(所有脚本同一套配置)
#    ROBOT_IP=192.168.8.147  LOCAL_IP=192.168.8.185  ARM_PORT=8080
grep -n "ROBOT_IP\|LOCAL_IP" *.py

# 3) 确认所有真实运动开关处于关闭
grep -n "^ENABLE_REAL_MOTION" *.py     # 应全部 = False
```

**通用安全约定（每个脚本都一样）**：

1. 先 `ENABLE_REAL_MOTION = False` 干跑一遍——只打印计划和限位校验，不动机器人；
2. 计划无误后改 `True` 重跑，全局速度已设为 3~5%，人守在急停旁；
3. 交互式确认：每个姿态前按回车执行，输 `q` 中止（已采样本会自动保存）；
4. **跑完立刻把开关改回 `False`**（脚本结束时也会提醒）。

## 1. Session 1：腕部姿态采样（约 20 分钟，最优先）

服务：UVW 约定判别 + TCP 偏移拟合（一批数据两用）。

```bash
# 先用你现有的关节运动脚本把左臂摆到之前采样的安全姿态附近:
#   [22, 17, 0, -78, 3, 2, 3] (deg)
# 脚本会把"运行时的当前姿态"作为 base, 12 个目标都相对 base 摆腕部 j5/j6/j7。

python3 collect_wrist_orientation_samples.py        # 干跑
# 检查打印的 12 个目标角度全部 ✓ 无越限
# 改 ENABLE_REAL_MOTION=True 后重跑, 逐姿态回车确认
```

产出：`data/wrist_orientation_samples_latest.json`（另有时间戳备份版）。

## 2. 定点触碰标定（约 40~60 分钟）

服务：直接解出夹爪指间中心在腕部 link11 系的偏移 r（抓取最终要用的量）。

**先准备道具**：工作区内固定一个尖点参照物（顶针/螺栓尖/笔尖朝上，夹稳，
全程绝不能碰动）。

```bash
python3 jog_and_record_touch.py     # 改 ENABLE_REAL_MOTION=True 后 j 命令才会动
```

交互命令：

| 命令 | 作用 |
|---|---|
| `j5 2.5` | SDK 关节 5 转 +2.5°（单步限 ±5°，自动限位校验） |
| `read` | 读取并打印当前关节角 + XYZ/UVW |
| `rec 名字` | 记录当前姿态为一次触碰样本 |
| `undo` / `list` | 删除最后一条 / 列出已记录 |
| `save` | 保存 JSON |
| `q` | 退出（有未保存记录会自动保存） |

操作要领：用 `j` 命令引导**夹爪指间中心**轻触尖点 → `rec touch_01`；
换一个**相差 30° 以上**的腕部朝向再触同一点 → `rec touch_02`；
至少 3 次，建议 4~5 次。

产出：`data/touch_samples_latest.json`。

## 4. 命令侧 UVW 单轴验证（每次一个轴）

服务：确认 `armMoveWorlds` 下发侧与反馈侧约定一致 + TCP 行为判别。
**前提：Session 1 数据已在 Mac 上完成 UVW 判别之后再做。**

```bash
# 顶部配置: AXIS="U"  DELTA_DEG=5.0  (首测就用 5, 别加大)
python3 verify_uvw_command_side.py
# 观察: 腕部绕哪根物理轴转、方向是否符合预测;
#       XYZ 理论不变 —— 看哪个物理点保持不动(指尖=TCP / 手腕=腕点)
# 改 AXIS="V"、"W" 各重复一次
```

## 5. 轨迹执行（pick-and-place 真机复现）

服务：回放 Mac 上 `pick_place_coord` 仿真导出并校验通过的关节轨迹。

```bash
# 轨迹 JSON 从 Mac 拷到本目录后:
python3 execute_trajectory.py traj_latest.json     # 干跑: 复验+打印分段计划
# 确认计划后改 ENABLE_REAL_MOTION=True 重跑, 每段回车确认, q 随时中止
```

要点：
- 轨迹里的 `q_sdk_deg` 已含 j6 符号翻转，执行器会复验 `meta.j6_flipped` 标记；
- 首次真跑：空爪低速全流程 → 悬停 pick 点时把方块摆到夹爪正下方 → 完整流程；
- 夹爪串口命令与 §2.1 实测的一致（`GRIPPER_ID=1` 左夹爪，如实际为 2 改配置）；
- 当前姿态离首路点超过 20° 会要求显式确认，确认路径上无障碍再继续。
